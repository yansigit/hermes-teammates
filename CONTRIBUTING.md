# Contributing to hermes-subagents

This is a fork of [hermes-teammates](https://github.com/100yenadmin/hermes-teammates). Problems in the fork's own
features (model-named spawns, resumed follow-ups) belong in
[this repository's issues](https://github.com/yansigit/hermes-teammates/issues). Problems that also happen with
upstream hermes-teammates belong upstream, and problems in Hermes itself in
[NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent/issues).

Include `hermes --version`, the plugin version from `hermes plugins list`, and the `resume_skipped` text if a
follow-up did not resume. Development setup, tests and repository rules are in [AGENTS.md](AGENTS.md).
